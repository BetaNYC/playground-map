# playground-map

Pulls data from [bigapps feed](http://www.nycgovparks.org/bigapps) and allows for filters for locations and types. Based on NYC Park's [playgrounds page](https://www.nycgovparks.org/facilities/playgrounds) and tiles from their map.
## What's changed

Fixes and corrections to the map, newest first, are in [`WHATS-CHANGED.md`](WHATS-CHANGED.md) and on the site at https://playgrounds.beta.nyc/whats-changed.html. The page is built from the file by `npm run whats-changed` (also run before every build), and `npm test` plus the "What's changed" workflow check both on every pull request.
